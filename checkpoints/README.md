# Checkpoints

This folder contains intermediate project submissions completed throughout the course.

## Contents

- **checkpoint_1.ipynb**  
  Focuses on dataset selection, preprocessing, and exploratory data analysis (EDA).  
  Key outputs include graph statistics, centrality analysis, community structure, and initial embedding exploration.

- **checkpoint_2.ipynb**  
  Focuses on research question formulation and methodological planning.  
  Defines the main research question, proposes evaluation strategies, and establishes the direction for the final project.

## Purpose

These checkpoints document the progression of the project from initial data understanding to a well-defined research problem.

They provide context for:
- Why the dataset was chosen  
- How key structural properties were identified  
- How the final research question evolved  

## Notes

- The final implementation and results are presented in `main_notebook.ipynb`  
- Checkpoints are included for completeness and reproducibility
