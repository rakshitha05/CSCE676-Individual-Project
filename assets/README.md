# Assets

This folder contains visual outputs and presentation materials for the project.

## Contents

- spectral_embedding.png  
  PCA visualization of spectral embedding colored by structural roles

- node2vec_embedding.png  
  PCA visualization of node2vec embedding colored by structural roles

- embedding_comparison.png  
  Side-by-side comparison of spectral and node2vec embeddings

- role_distribution.png  
  Distribution of node roles in the graph

- results_table.png  
  Summary of evaluation metrics

- final_presentation.pptx  
  2-minute project presentation

## Purpose

These visuals support the analysis and help illustrate the key findings of the project:
that spectral embedding preserves structural roles better than node2vec.
